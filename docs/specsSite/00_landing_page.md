# Требования к лендинговой странице (Крестики-Нолики AI)

## Общие требования
- Адаптивная вёрстка (мобильные устройства, планшеты, десктоп).
- Поддержка современных браузеров (Chrome, Firefox, Safari, Edge).
- Время загрузки страницы не более 2 секунд.
- Все интерактивные элементы должны иметь состояния `:hover`, `:focus`, `:active`.

---

## 1. Шапка (Header)
- **Левый угол:** Логотип / Название сайта — **«Крестики-Нолики AI»**.
- **Правый угол:** 
  - Иконка профиля (пиктограмма «человечка») ИЛИ кнопка «Войти».
  - Если пользователь не авторизован — отображается кнопка «Войти».
  - Если пользователь авторизован — отображается аватар (инициалы или фото) и выпадающее меню с пунктом «Выйти».

---

## 2. Общее описание (Hero-блок)
- Краткий слоган (например: *«Играй в классические крестики-нолики против сильного AI»*).
- 1–2 предложения о преимуществах (например: *«Выбери уровень сложности, сражайся с LLM-моделями и анализируй свои партии»*).

---

## 3. Кнопка «Начать новую игру»
- Крупная, контрастная, стилизованная (градиент, тень, анимация при наведении).
- При клике:
  - Если пользователь не авторизован → открывается модальное окно входа/регистрации.
  - Если авторизован → создаётся новая игровая сессия и выполняется редирект на страницу игры (открывается в той же вкладке).

---

## 4. Кнопка / Блок «Войти»
- Располагается рядом с блоком описания или под ним.
- Содержит краткий текст (например: *«Уже есть аккаунт? Войдите, чтобы сохранять историю игр»*).
- Кнопка «Войти» открывает модальное окно с формами:
  - **Вход** (email / verification code).
  - **Регистрация** (email, username, verification code).
  - Возможность переключения между формами (табы или ссылка «Зарегистрироваться»).

---

## 5. Карусель со списком предыдущих игр
- Отображается только для авторизованных пользователей.
- Если игр нет — показывается заглушка: *«Вы ещё не играли. Начните первую игру!»*.
- **Каждая карточка игры содержит:**
  - Дата и время начала.
  - С кем игра (например: «LLM: GPT-4», «LLM: Claude», «Против друга»).
  - Параметры игры (размер поля, сложность, кто ходит первым).
  - Прогресс (% завершённости) в виде прогресс-бара.
- **Если игра не завершена (прогресс < 100%):**
  - Кнопка «Продолжить» → открывает страницу игровой сессии в **новой вкладке**.
- Карусель с возможностью листать влево/вправо (стрелки или свайп).

---

## 6. Описание функций (интерактивный аккордеон/спойлеры)
- Блок с заголовком: *«Что вы можете делать в игре»*.
- Каждая функция — это кликабельный заголовок.
- При клике раскрывается блок с подробным описанием.
- **Минимальный набор функций:**
  1. **Игра против AI** — выбор LLM-модели, настройка сложности.
  2. **Игра вдвоём** — режим для двух игроков на одном устройстве.
  3. **История партий** — просмотр всех сыгранных игр с деталями.
  4. **Анализ ходов** — просмотр оптимальных ходов после окончания игры.
  5. **Настройки внешнего вида** — смена темы (светлая / тёмная).

---

## 7. Карусель с описанием используемых LLM моделей
- Горизонтальная прокрутка карточек.
- **Каждая карточка содержит:**
  - Название модели (например, GPT-4o, Claude 3.5 Sonnet, YandexGPT, LLama 3).
  - Производитель (OpenAI, Anthropic, Яндекс, Meta).
  - Дата выхода (или дата последнего обновления).
  - Особенности / ключевые характеристики (например, *«высокая скорость», «хорошая тактика», «креативность»*).
  - Иконка или логотип модели/производителя.
- Возможность остановить автопрокрутку при наведении.

---

## 8. Подвал (Footer)
- Тёмный фон, контрастный текст.
- Содержит:
  - Ссылка на «Политику конфиденциальности» (открывается в новой вкладке).
  - Ссылка на GitHub-репозиторий проекта (с иконкой GitHub).
  - Копирайт (например, © 2026 Крестики-Нолики AI).
  - Контактная почта для связи (опционально).

---

## Технические требования
- Модальное окно входа/регистрации должно быть доступно по клавише `Esc`.
- Карусели реализовать с использованием `IntersectionObserver` для ленивой загрузки.
- Все внешние ссылки открываются в новой вкладке (`target="_blank" rel="noopener noreferrer"`).
- Для карусели с играми — пагинация или подгрузка по 5 карточек за раз.
- Для аккордеона (описание функций) — плавная анимация раскрытия (высота, opacity).

---

## Макеты и визуальные референсы (для дизайнера)
- Цветовая схема: тёмно-синий (основной), акцентный — оранжевый/золотой.
- Шрифты: без засечек (например, Inter, Roboto).
- Скругления: 8–12 px для карточек, 20–30 px для кнопок.
- Тени: лёгкие, с размытием 10–20 px.
